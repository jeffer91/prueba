Importante sobre seguridad

Esta página usa el SDK web de Firebase y, por tanto, respeta las reglas de seguridad de Cloud Firestore. No coloques una cuenta de servicio ni claves privadas dentro de este repositorio. Si las reglas no permiten la lectura desde esta página, la app mostrará el error sin intentar evadirlo.
